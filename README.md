# 🛒 Meesho E-Commerce Analytics Dashboard

An interactive Power BI dashboard built to analyze Meesho e-commerce sales performance, order trends, delivery metrics, cancellations, GST, and state-wise sales insights. This project demonstrates data visualization, DAX calculations, KPI tracking, and business intelligence reporting.

## 🚀 Project Overview

This dashboard helps monitor key business metrics and provides actionable insights into sales performance across different states and order statuses.

### Business Objectives

- Analyze total sales and order performance
- Monitor Average Order Value (AOV)
- Track delivery and cancellation rates
- Compare weekly order trends
- Identify top-performing states
- Visualize cumulative sales contribution

---

## 📌 Key KPIs

- 💰 Total Sales
- 📦 Total Orders
- 🛍 Average Order Value (AOV)
- 🚚 Delivery Percentage
- ❌ Cancellation Percentage
- 🧾 Average GST

## 📂 Data Model

The dashboard uses:

- Fact Table
  - Sales Transactions

- Dimension Tables
  - Date Table

Relationships were created using a Star Schema for better performance.

---

## 📊 DAX Measures Used

Some important measures include:

- Total Sales
- Total Orders
- Average Order Value (AOV)
- Delivery %
- Cancellation %
- Average GST
- Sales Growth %
- Orders Growth %
- Dynamic KPI Summary

---

## 💡 Business Insights

- Uttar Pradesh generated the highest sales.
- Weekly order volume peaked during Week 35.
- Delivery rate is significantly lower than the overall order count, indicating room for operational improvement.
- Cancellation rate remains below 3%, reflecting healthy order fulfillment.
- A small number of states contribute the majority of total sales.
